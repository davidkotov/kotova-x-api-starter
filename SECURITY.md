# Security

Please do not report security problems in public issues or pull requests.

Report a vulnerability in this example app, or in the Kotova X API it calls,
through the Kotova bug bounty:
https://docs.kotova.io/x/security/bug-bounty

This repository is example code. If you build on it, the security of your
deployment is yours to own: read "Before you deploy" in the README first.
